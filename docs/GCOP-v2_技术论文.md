## 摘要

轻量级内容混淆在防随手阅读、防爬虫抓取等场景中需求广泛，但自制混淆方案普遍存在**结构泄露**：位移偏置、分区保留、代数塌缩等缺陷使密文在统计检验或代数分析面前不堪一击。本文在循环轨道置换（Generalized Cyclic Orbit Permutation, GCOP）的基础上提出 **GCOP-v2** 体系，核心贡献有三：（1）发现并形式化了一类**长度诱导的代数塌缩漏洞**——当文件长度为质数时参数生成被迫退化，多轮变换整体塌缩为模 n 仿射映射，参数空间从 n! 坍缩至 n·φ(n)，我们给出完整的无钥匙攻击链并在约 41 万候选空间内实测破译；（2）提出**长度自适应填充策略**与**参数域安全约束**（组数下限、互素步长、退化组合拒绝），从构造上消灭该塌缩档与全部小参数空间档，使最弱参数档的密钥空间下界从 2¹⁹ 提升至 2⁹⁶；（3）提出一套基于**排列不变量 + 蒙特卡洛零分布对照**的黑盒统计验证方法，以 7 项不变量证实 v2 输出在无钥匙攻击者的全部可观测维度上与均匀随机置换不可区分。正确性方面，给出闭式逆变换与散射重建的还原算法，在 0~5000 字节共 10 种尺寸下通过逐字节往返验证。

**关键词**：位置置换；混淆；结构泄露；仿射塌缩；参数域约束；统计均匀性；蒙特卡洛零分布

**Abstract**: Homemade obfuscation schemes commonly suffer from *structural leakage*. Building on the Generalized Cyclic Orbit Permutation (GCOP), we present GCOP-v2, which (i) identifies and formalizes a *length-induced algebraic collapse*: for prime-length inputs the parameter generator degenerates and the whole multi-round transform collapses to a single affine map modulo n, shrinking the search space from n! to n·φ(n) — an attack we demonstrate end-to-end; (ii) introduces *length-adaptive padding* and *parameter-domain constraints* that eliminate the collapse and all small-space regimes, raising the weakest-space lower bound from 2¹⁹ to 2⁹⁶; and (iii) proposes a black-box verification methodology combining permutation invariants with Monte-Carlo null distributions, under which v2 output is indistinguishable from uniformly random permutations across 7 invariants.

## 1 引言

### 1.1 背景与动机

在游戏脚本分发、配置文件保护、网页内容防抓取等场景中，使用者往往需要的不是密码学强度的加密，而是**低成本的确定性内容置乱**：无口令、无文件头、开销极小、可用一把小巧的"钥匙"文件还原。这类需求下，基于字节位置置换的混淆方案是最自然的选择。

然而，自制置换类混淆方案的失效模式高度一致——**不是置换空间不够大，而是置换族的结构可被观测**：

- 位移分布有偏（字节总落在原位置附近）；
- 分区保留（字节永远困在固定分组内）；
- 代数塌缩（多轮变换等价于一个可枚举的简单函数族）；
- 低阶循环（默认参数组合下高次幂回归恒等）。

本文作者在 GCOP 系列工作 [1] 中提出了具有闭式逆变换的循环轨道置换框架；本文是该框架的 **v2 加固版**，其设计直接来源于一次完整的红蓝对抗评估——攻击方在**未接触源码**的前提下，仅凭密文与钥匙文件完成了对 v1 版本的无钥匙破译与有钥匙完全逆向，所有发现均反馈至 v2 的构造中。

### 1.2 本文贡献

1. **发现并形式化长度诱导的代数塌缩**（第 4.2 节）：证明当文件长度 n 为质数时，参数生成器被迫取 g=1，多轮复合整体塌缩为模 n 仿射映射 `S(x) = α·x + β (mod n)`，有效密钥空间从 O(n!) 坍缩至 n·φ(n)。给出完整无钥匙攻击链并在 n=643 上以约 41.3 万候选实测破译。
2. **长度自适应填充与参数域约束**（第 3 节）：通过"16 字节块对齐 + 最短 128 字节 + 随机附加块 + 密码学随机填充"的填充策略与组数下限 g ≥ 8 的参数域约束，从构造上使仿射塌缩档与全部小参数空间档不可达，最弱档密钥空间下界提升至 2⁹⁶。
3. **黑盒统计验证方法论**（第 4.3 节）：提出以排列不变量（下降数、循环数、LIS、模均匀性、锚点位移、bigram 存活）结合**蒙特卡洛零分布对照**的验证流程，并记录三个典型的统计假象作为方法论警示。
4. **完整的参考实现**：CLI 与拖拽式 GUI 双通道、v2 钥匙格式（含填充长度字段）、对 v1 钥匙的后向兼容，以及 0~5000 字节共 10 种尺寸的逐字节往返验证。

### 1.3 诚实定位

本文方案是**纯位置置换混淆**，不是加密：字节值与频率分布不变，一对同长度已知明文即可恢复当次钥匙。其安全目标是**无钥匙场景下的统计与计算不可区分性**，不对抗已知明文攻击者。该定位与 [1] 第 9.4 节一致。

## 2 预备知识与记号

设明文为字节串 `P = P[0] P[1] … P[n-1]`。一个**置换**记为双射 `π: Z_n → Z_n`；本文统一采用 **gather 约定**：`C[w] = P[π(w)]`，即 `π(w)` 表示输出位置 w 的内容来源于输入位置 π(w)。散射视角为其逆：字节 `x` 的目标位置为 `π⁻¹(x)`。

**定义 1（GCOP 单轮读索引）**. 设 `n = g·L`（`g` 为组数，`L` 为组内长度），参数为组排列 `σ: Z_g → Z_g`、相位 `a = (a_0,…,a_{g-1}) ∈ Z_L^g`、步长 `q = (q_0,…,q_{g-1})`（各 `q_r` 与 `L` 互素）。GCOP 单轮读索引定义为：

```
m[r·L + j] = σ(r) + g · ((a_r + q_r · j) mod L)，   r ∈ [0,g), j ∈ [0,L)
```

即输出第 `r` 组的第 `j` 个字节取自输入第 `σ(r)` 组的第 `(a_r + q_r·j) mod L` 个字节——**跨步读组、组内仿射、连续写回**。

**引理 1（单轮双射性）**. `m` 为双射当且仅当 σ 为双射且各 `gcd(q_r, L) = 1`。

证明：σ 保证组的重排为双射；组内映射 `j ↦ (a_r + q_r·j) mod L` 在 `q_r` 与 `L` 互素时为 Z_L 上的仿射双射。∎

**定义 2（多轮复合）**. 记 `M` 为定义 1 的读索引（gather 形式），复合 `rounds` 轮的总读索引为 `M⁰ = id`，`M^{k+1}[w] = M[M^k[w]]`，总变换即 `C[w] = P[M^{rounds}[w]]`。

**注**：gather 复合与逐轮施加等价，且总计算量为 O(rounds·n)。实现上应一次性构建复合表再置换，避免大文件逐轮搬运。

## 3 GCOP-v2 体系设计

### 3.1 总体架构

```
明文 P ──► ① 长度自适应填充 ──► P′ (n′ 字节)
              │
              ▼
       ② 参数生成 (g, σ, a, q, rounds)   ──► 钥匙 K (JSON, 含 pad 字段)
              │
              ▼
       ③ 复合读索引 M = M^rounds          ──► C[w] = P′[M[w]]
```

### 3.2 长度自适应填充策略

**算法 1（填充）**. 输入明文 `P`（长度 n）：

1. `blocks ← ⌈max(n,1) / 16⌉`；
2. `target ← max(128, blocks·16) + 16·U{0,1,2}`，其中 U 为均匀随机整数；
3. `pad ← target − n`；若 `pad > 0`，追加 `pad` 个 `os.urandom` 字节。

输出 `P′ = P ∥ R`（`R` 为随机填充串），`n′ = |P′| = |P| + pad`。

**引理 2（填充的存在性保证）**. `16 | n′` 且 `n′ ≥ 128`，故 `8` 是 `n′` 的真因子，且 `8 ≤ n′/2`。因此闭区间 `[8, n′/2]` 内恒存在参数域合法的 `g`，第 3.3 节的参数生成**永不需要**回退到 g=1。

设计动机：填充长度取随机 0~2 个附加块以模糊真实长度指纹；填充内容取密码学随机字节以避免零填充的统计指纹（零填充会在密文直方图中引入可数的 0x00 群）。

### 3.3 参数域约束

在 `n′` 确定后，参数生成遵循以下约束：

- **组数下限**：`g` 从 `[8, min(n′/2, 1024)]` 内的真因子中均匀随机选取。下限 8 保证 `σ` 的空间至少 `8! ≈ 2^15.3`，消灭 v1 中 g ∈ {1,2,3,4} 的全部小空间档（g=1 仿射塌缩档约 2^19，g=4 档约 2^40）；
- **互素步长**：各 `q_r` 从 `{k ∈ [1,L) : gcd(k,L)=1}` 中均匀随机，保证引理 1 的双射性；
- **相位**：各 `a_r ∈ [0, L)` 均匀随机；
- **轮数**：`rounds ∈ [8, 24]` 均匀随机；
- **退化组合拒绝**：若 `σ = id` 且 `a = 0` 且 `q = 1`（全默认组合，低阶对合，高偶数次幂回归恒等）则重抽；对 `n′ ≤ 2^16` 的文件额外完整校验复合读索引非恒等。

**引理 3（g=1 档不可达）**. 由引理 2 与组数下限，v2 正常流程下 `g ≥ 8`，第 4.2 节的仿射塌缩攻击面不存在。

### 3.4 钥匙格式

```json
{"type": "gcop-key", "version": 2, "n": 656, "g": 82, "pad": 13,
 "sigma": [...], "a": [...], "q": [...], "rounds": 21}
```

`pad` 记录填充长度；`version` 1（无 pad 字段）的旧钥匙按 `pad = 0` 处理，后向兼容。

### 3.5 还原算法

**算法 2（还原）**. 输入密文 `C` 与钥匙 K：

1. 由 `(g, σ, a, q)` 重建单轮读索引 `M`，按定义 2 复合 `rounds` 次得总读索引；
2. 散射重建：`P′[M[w]] ← C[w]`（对所有 w）；
3. 裁剪：输出 `P′[0 : n′ − pad]`。

**定理 1（还原正确性）**. 对任意满足引理 1 的参数与任意轮数，算法 2 输出恰好等于填充前的明文。

证明思路：`M` 为双射，散射重建即 `P′[M[w]] = C[w] = P′_orig[M[w]]` 的逐位复原；填充字节位于尾部，按 `pad` 裁剪即得原文。∎

## 4 安全性分析

### 4.1 攻击者模型与泄露面

设攻击者持有：密文 `C`、（可公开获取的）算法描述。可选持有：钥匙（密钥泄露场景）或同长度已知明文（已知明文场景）。

纯置换的**固有泄露面**（与本文设计无关，任何置换方案共有）：字节直方图、文件长度（填充后模糊至 ±48 字节窗口）、由直方图可判定的内容类型。v2 的随机填充额外将填充噪声混入直方图，轻微稀释内容统计。

### 4.2 长度诱导的代数塌缩（v1 漏洞的形式化）

**引理 4（g=1 塌缩）**. 当 `g = 1, L = n` 时，定义 1 退化为 `m[w] = (a + q·w) mod n`，即模 n 仿射映射；`rounds` 次复合仍为仿射：

```
m[w] = α·w + β (mod n)，  α = q^rounds mod n，  β = a·(q^rounds − 1)/(q − 1) mod n
```

**推论 1**. 此时有效密钥空间为 `n·φ(n)`（与 n·φ(n) 成正比的候选数），而非 n!。对 n = 643（质数）：412,806 个候选。

**攻击实测（v1）**. 密文为 643 字节的 UTF-8 中文与 Lua 混合文本。攻击者在**不持有钥匙**的前提下：由 n 为质数推断 g=1 → 枚举全部 (α, β) 候选 → 以"前 12 字节 UTF-8 可解码"早停 + 全文可打印率 >95% 筛选 → 41.3 万候选中唯一锁定 α=135，全文还原（约 400 个等价 β 构成同一明文的循环旋转等价类，精确解存在，信息零损失）。全程约 2 分钟（纯 Python，含早停）。注意：枚举时必须过滤 `gcd(α,n) > 1` 的候选——非互素 α 产生周期性退化序列（如 3 字节循环 52 次），会构成合法 UTF-8 假阳性。

**v2 修复验证**. 对同内容文件按 v2 填充至 n′=656 后重放该攻击：209,920 个候选中 0 个通过全文验证——塌缩攻击面不复存在。

### 4.3 参数空间分析

**定理 2（最弱档下界）**. v2 下任意文件的参数空间满足

```
|Space| ≥ min over 合法 g ∈ [8, n′/2] of  g! · L^g · φ(L)^g · |R|，  L = n′/g，|R| = 16
```

实测最弱档出现在最小填充长度 n′=160、g=8、L=20 处：`8! · 20^8 · 8^8 · 16 ≈ 2^78`；典型文件（n′ ≥ 656）≥ 2^113。跨 10 种尺寸（0~5000B）实测钥匙的最小参数空间为 2⁹⁶。

对比 v1：g=1 档 2^19（41 万候选）、g=4 档 2^40——两者均已在 v2 中不可达。

**关于"结构族 vs 全置换空间"的诚实说明**：GCOP-v2 的净置换生活在参数族（约 2^78~2^176）内，是 n!（如 643B 文件 2^5077）的真子集。本文不以"覆盖全置换空间"为安全声明，而以（a）族成员在无钥匙下不可观测（引理 3 消灭塌缩后，4.3 节统计检验支持该论断）、（b）族本身大到枚举不可行为安全依据。这一权衡换取了紧凑钥匙（百字节级）与 O(rounds·n) 的闭式可逆性。

### 4.4 统计均匀性验证

对全异字节文件（n=255，值 1..255 互异）单次运行即可获得完整置换 π，检验其与均匀随机置换的偏离（理论期望值均标注）：

| 检验项 | 实测 | 均匀随机期望 | 结论 |
|---|---|---|---|
| 下降数 | 125 | 127.0 ± 4.6 | 通过 |
| 循环数 | 9 | 6.12 ± 2.12 | 通过 |
| χ²（q(i) mod 8）| 0.0 | < 14.07（df=7, 95%）| 通过 |
| χ²（(q(i)−i) mod 8）| 4.4 | < 14.07 | 通过 |
| 最长递增子序列 LIS | 26 | ≈ 32 ± 3.6 | 通过 |
| 唯一字节锚点位移 | 中位 248，最大 561（87% n）| 全局散布 | 无局部性 |
| bigram 邻接匹配（蒙特卡洛 2000 次）| 235 | 229.4 ± 13.7（Z=0.4）| 通过 |

**方法论警示**：随机性检验中直觉最先被欺骗。我们的三轮假阳性记录——(1) 标记位置排序配对后的"单调保持"不携带信息；(2) 均匀随机置换的期望位移恰为线性斜线 E[π(i)−i] = (n−1)/2 − i；(3) 重复 bigram（双空格 ×63 等）使邻接匹配的朴素期望失效。所有结论必须以**蒙特卡洛零分布对照**复核。

### 4.5 已知明文与密钥泄露

- **已知明文**：一对同长度明密文即恢复当次全部参数（置换的本性，作者在 [1] 中已声明）。由于每轮参数逐文件独立随机，该恢复**不可迁移**至其他密文。
- **密钥泄露**：钥匙为 JSON 明文，包含全部变换参数；算法本身随实现公开。因此密钥泄露等价于完全破译——这是纯置换混淆的正确性质，也是唯一命门。工程建议：钥匙与密文分离渠道分发；如需对抗密钥泄露后的大规模批量还原，应转向标准加密（如 AES-GCM）。

## 6 局限与讨论

1. **纯置换天花板**：字节频率、长度（±48B）必然泄露；需要机密性与完整性时应使用标准加密并附加 MAC。
2. **已知明文不可对抗**：任何纯置换共有；若威胁模型包含已知明文，本方案不适用。
3. **参数族的子集性**：净置换非 S_n 均匀采样；本文以"族不可观测 + 族足够大"为安全依据，若未来出现针对 (A∘F)^r 型复合置换的族识别攻击，应重新评估。
4. **随机源依赖**：参数由 `random.SystemRandom` 生成，安全性依赖操作系统熵池。

## 附录 A：专利风格权利要求（草拟，供专利申请参考）

**权利要求 1**. 一种基于多轮循环轨道置换的文件混淆方法，其特征在于包括以下步骤：S1）对输入文件执行长度自适应填充，使填充后长度 n′ 为预设块尺寸的整数倍且不小于预设最短长度；S2）在参数域约束下随机生成混淆参数，所述参数包括组数 g、组排列 σ、各组相位 a 与互素步长 q、轮数 rounds；S3）以所述参数构建单轮读索引并复合 rounds 轮得到总读索引；S4）按总读索引对填充后文件执行字节置换得到密文；S5）将包括填充长度在内的全部参数写入钥匙文件。

**权利要求 2**. 根据权利要求 1 所述的方法，其特征在于：所述填充的目标长度为 16 字节块对齐且不小于 128 字节，并随机追加 0 至 2 个整块以模糊原始长度；填充内容为密码学随机字节。

**权利要求 3**. 根据权利要求 1 所述的方法，其特征在于：所述组数 g 从区间 [g_min, n′/2] 内的 n′ 真因子中随机选取，且 g_min ≥ 8；所述填充保证该区间内恒存在真因子。

**权利要求 4**. 根据权利要求 1 所述的方法，其特征在于：各组步长 q_r 从与组内长度 L 互素的整数中随机选取，以保证单轮读索引为双射。

**权利要求 5**. 根据权利要求 1 所述的方法，其特征在于：当组排列、相位、步长构成预设的默认组合时拒绝该组参数并重新生成；和/或当复合读索引为恒等映射时重新生成。

**权利要求 6**. 根据权利要求 1 所述的方法，其特征在于：所述钥匙文件包含版本字段与填充长度字段，还原时按填充长度裁剪还原结果的尾部。

**权利要求 7**. 一种文件还原方法，其特征在于：读取密文与配对钥匙；按权利要求 1 所述参数重建多轮复合读索引；以散射方式将密文按读索引写回得到填充后明文；按钥匙中的填充长度裁剪输出。

**权利要求 8**. 根据权利要求 1 所述的方法，其特征在于：输入为扩展名为 .gcop 的文件时自动执行权利要求 7 所述还原方法，否则执行混淆方法。

## 附录 B：统计检验清单（可复用规程）

对全异字节文件（长度 n ≤ 255，值 1..n）执行一次混淆，得到完整置换 π，依次检验：

1. 长度与多重集保持（置换性）；
2. 下降数 ≈ (n−1)/2 ± √((n+1)/12)；
3. 循环数 ≈ ln n + γ ± √(H_n − H_n²)；
4. χ² 模均匀性：π(i) mod m 与 (π(i)−i) mod m（m=8，临界值 14.07）；
5. LIS ≈ 2√n；
6. 唯一字节锚点位移分布（判断局部性/全局性）；
7. bigram 邻接匹配数对比**蒙特卡洛零分布**（≥2000 次随机置换），以 Z 分数判定。

警示：任何"结构发现"必须先与零分布对照——位置排序配对的单调性、期望位移斜线、重复 bigram 膨胀是三个实测踩过的假阳性来源。
